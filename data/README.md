# Zenodo data

Download the files listed in the repository's `DATA_MANIFEST.csv` from the
associated Zenodo record and place them in this directory. The serialized data
objects are intentionally excluded from GitHub by `.gitignore`.

The normal public workflow starts with `WholeOE.rds` in this directory and
notebook `03_extract_olfactory_lineage.Rmd`. See the main `README.md` for the
input required by each downstream notebook.
